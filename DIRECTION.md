# Sightline direction

The Hypersite seeded draft (`1084293893`) selected a warm photographic world. This contract deliberately replaces its image-displacement role and gallery-like section plan because the requested product is an interactive 3D teaching tool. The warm analog ground survives; the user action governs composition.

**Brief:** Sightline: an interactive school crossing visibility simulator.

## Committed direction

| Axis | Decision |
|---|---|
| Theme | Warm analog road-survey exhibit; chalk paper, asphalt ink, muted marker orange |
| Surface | Quiet paper fields, one dark simulator stage, no decorative mesh gradient |
| Type | Self-hosted Satoshi Variable plus JetBrains Mono |
| Hero | Artistic asymmetry: two-line wide text left, generated crossing photograph in a distinct right/lower field; one primary action |
| Spine | Visibility: occluded edge, first sight, reaction travel, braking trace |
| Second read | A single orange line in the photo resolves as the same measured line in the simulator |
| Signature structures | Inline image typography, horizontal scenario accordion, restrained source strip, gapless three-part evidence grid |
| Motion | Pinned explanation chapter; scrubbed text reveal. Functional model updates are separate from page-wide scroll choreography. |
| 3D | Hero object: the working street diorama, not decoration |

## Seven-section plan

| Section | Job | Composition anchor | Surface | Media brief |
|---|---|---|---|---|
| 1. The hidden crossing | Name the problem and launch | Left-offset heading, photo to right and below | Chalk | Generated documentary-style crossing photo, van and waiting pedestrian; clearly identified as illustration |
| 2. Try the crossing | Working judge path | Wide left diorama, narrow right controls; mobile stacks | Asphalt | Rendered road, crosswalk, van, pedestrian, sight and stop marks |
| 3. Distance before sight | Explain the gap | Full-width text with central measured line | Chalk | Type-only, scrubbed sentence |
| 4. Three distances | Teach the model | Pinned left heading; right sequence | Warm gray | Authored geometric diagrams from the actual simulation parameters |
| 5. Change one thing | Compare choices | Full-width horizontal accordion and gapless evidence grid | Chalk | Rendered scenario diagrams, no stock placeholders |
| 6. The model, openly | Evidence and limits | Off-axis source column with open formula | Asphalt | Type and SVG geometry, no photograph slot |
| 7. Return to the street | Repeat action and credit | Giant left CTA, right closing note | Chalk | Type-only |

The hero is two lines on desktop. No section repeats the previous anchor. The first screen tells visitors what the tool does and how to start. All seven sections contain real content.
